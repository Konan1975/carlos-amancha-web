# 🌟 Sitio Web Personal - Carlos Amancha

## Descripción
Sitio web personal desarrollado con HTML5, CSS3 y PHP que incluye información biográfica, intereses, hobbies y un formulario de contacto funcional con almacenamiento en base de datos MySQL.

## Características
- ✅ Diseño responsive y moderno
- ✅ Validación de formularios (cliente y servidor)
- ✅ Almacenamiento de mensajes en base de datos
- ✅ Protección contra inyección SQL
- ✅ Mensajes de confirmación personalizados
- ✅ Navegación intuitiva

## Tecnologías Utilizadas
- **Frontend**: HTML5, CSS3, JavaScript
- **Backend**: PHP 7.4+
- **Base de Datos**: MySQL
- **Hosting**: InfinityFree
- **Librerías**: Font Awesome (iconos)

## Instalación Local

### Requisitos
- XAMPP, WAMP o MAMP
- Navegador web moderno

### Pasos
1. Clona o descarga este repositorio
2. Copia la carpeta a `htdocs` de XAMPP
3. Inicia Apache y MySQL en XAMPP
4. Crea la base de datos `carlos_amancha_db` en phpMyAdmin
5. Importa el archivo SQL incluido
6. Accede a `http://localhost/carlos-amancha-web/`
